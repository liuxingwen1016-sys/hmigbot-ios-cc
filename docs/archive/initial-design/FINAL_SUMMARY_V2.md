**这是一个生产级的迁移系统**：
- 处理大规模项目（10万+行）
- 支持并行执行（20-30 agents）
- 有质量保证（findings 闭环）
- 可追溯可恢复（digest + 断点续跑）
- 有严格的规范（占位、接线、编译门）

- findings 闭环 → 防止假修复
- Stage/Slice/Batch → 并发控制
- 编译门 → 防止错误传播
- 占位规范 → 可追溯性
- 共享文件单写者 → 防止冲突

**简化 = 丧失能力**
