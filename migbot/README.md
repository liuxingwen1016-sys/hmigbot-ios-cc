# HMigBot iOS for Claude Code

Migrate SwiftUI and UIKit projects to HarmonyOS ArkTS through the i2h Spec, Plan, Execute, Verify, and Retrospect stages. Use the repository installer with an existing HarmonyOS project directory, then run `/i2h-init` and `/i2h-run` in Claude Code. The installer requires Python 3. Native source inspection requires macOS and Xcode, and target build and device checks require DevEco Studio. The optional screenshot comparator requires Pillow and ImageHash.
