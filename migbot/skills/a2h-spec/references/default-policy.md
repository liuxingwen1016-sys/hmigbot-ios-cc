# 默认迁移原则

grill #1 / #2 对下列类目**不实时拷问**，直接按本文件裁定：C0 产出定位 / C2 迁移范围 / C5 死码与特殊页 / C12 原版缺陷 / C16 持久化 / C6·C8 无鸿蒙对等（plan 侧）。每条裁定写 ledger D 编号，`approval_source: default-policy` + 具体规则 + 源码证据，禁止伪造用户实时确认；同时逐条进 **确认表**（见文末）由用户在审批 Gate 整体确认或逐行改判。Plan、Execute、Verify 共同遵守，子任务不得扩大范围。

**不受本文件覆盖、仍实时拷问**：检出登录 / 鉴权链路或外部 API 时的 C15（测试账号 / 环境 / base_url）与 C17（契约不确定项，grill #2 分级问询）；C7 / C9 / C13 / C14；escape 候选；卫生闸 FAIL 项。auth-chain 探针（spec §C4.7b）照常无条件执行。

**无人值守（默认，见 [gate-handling.md](./gate-handling.md) §5）时上面这些也不等待回复**：C15 按「用户未提供测试环境」落 D 编号（依赖环境的验证记「阶段不可判定」，推到 a2h-verify）；
C17 / C7 / C9 / C13 / escape 取决策卡「← 推荐」项，C14 固定取「照源码」（见下「资料与签名」）；卫生闸 FAIL 项照常先修。确认表照样生成，随 Gate 自动确认，事后可逐行改判。

## 手机本体与排除项

- 完整复刻手机 App 本体的页面、弹窗、交互、状态、原有视觉和必要系统能力。通知、权限、持久化、后台任务等只要被手机功能实际依赖就保留，不以"屏幕外"排除。
- 排除桌面 Widget、穿戴 / 电视等独立扩展入口，以及仅供其使用的实现、资源和配置；手机本体共用部分保留。先判定入口和依赖，再生成范围内的页面 / 功能 Spec。
- 注释掉的代码、仅开发 Preview / 演示实现、确认不可达的死代码不迁移；保留许可证声明。零直接引用不是死码证据，须检查 Manifest、导航、反射、注入、系统回调和当前构建变体。无法排除真实入口时继续调查，不静默跳过。
- 排除项在 skip-list 记录路径 / 符号、理由、证据与项目 D 编号；不生成 stub Spec。覆盖率按手机迁移范围统计，范围外项单列，不伪称全仓实现。

## 原版行为与缺陷

- 保留源码 / 运行证据确定的原有行为，包括缺陷、空点击、未完成功能和异常分支；不借迁移补业务或优化体验，也不新增一次全面找 bug 的审计。
- 已确认原有缺陷 / 空行为写在对应 AC：源码锚点、触发条件、原结果、目标预期。Execute 和 Verify 只修迁移引入的偏差，不把原版缺陷当修复任务。
- 原有空行为不计作待实现 TODO；对应扫描 finding 必须逐项关联 AC 和证据后裁定，不全局屏蔽空回调 / 崩溃检查。发现新的、未证明来自源端的问题仍阻断。
- 允许目标平台必要的语法、生命周期和资源适配；不允许擅自改变可观察行为。无法等价复刻时记 PD-* 保持 proposed 进确认表，不自行替换或降级。

## 存储：只迁移键，不搬用户数据

- 迁移手机功能实际使用的存储键、命名空间、字段 / 表结构、值类型、源码默认值及读写语义；目标从全新安装状态开始。
- 不读取、导出、导入用户设备上的偏好值、数据库记录、账号 / token、历史记录或用户文件；不实现 Android 旧数据搬迁、旧版本兼容或导入向导。
- 源码自带的静态商品、图片、种子数据和默认配置属于 App 内容，仍复刻。目标运行后仍可正常保存新产生的数据。

## 资料与签名

- 官方技术文档查询用于确认平台 API；"无外部资料"不代表禁止技术查证，也不允许推测未知后端契约。影响范围内行为的关键事实不足则记录 blocking。
- 默认不签名，产出 unsigned HAP；不创建、修改或自动配置签名，不因缺少证书 / 账号阻塞 unsigned 构建。保留工程已有签名配置；若它与所请求产物冲突，明确报告，不擅自删除配置。
- 只有显式要求 signed HAP 时才校验工程已有签名配置和材料；缺失则报告阻塞，不自动生成签名、不借用其他项目密钥。签名材料（HAP 签名证书、profile 及其密码）和实际用户数据不进入 Spec / 日志 / 提交。
- **源码里写死的接口签名 key / appId / secret / 网关地址属于 App 内容，不是部署材料**（C14 默认＝照源码）：实现时按源码原值写进代码，网络客户端在启动装配处创建并注入；不能以「部署配置」「密钥不入包」为由把它延后或登记成延后项（gpt1030_3 因此整个网络层从未创建，登录 / 模板全不可用）。spec 文档里这类值只落名和 `文件:行`（见 android-api-inventory output_schema），不粘值。要改安全架构（服务端代签、混淆等）须用户明确要求并记 D 编号。
